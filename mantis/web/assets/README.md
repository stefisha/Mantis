# Brand assets

`mantis-mark.png` and `coralabs-mark.png` are the original embedded images extracted from the project presentation supplied by the repository owner. They are used as project branding, not redistributed under the font licenses.

Headings use Anton and interface labels use Space Mono, matching the presentation. These fonts are served locally, with no third-party font requests:

- Anton: https://github.com/google/fonts/tree/main/ofl/anton (`Anton-OFL.txt`)
- Space Mono: https://github.com/google/fonts/tree/main/ofl/spacemono (`SpaceMono-OFL.txt`)

Both fonts are distributed under the SIL Open Font License 1.1. The interface uses the presentation's orange (#FF9F00), black canvas, white type, and grid motif.

The product and workspace interfaces use self-hosted Inter and JetBrains Mono, with licenses in `Inter-OFL.txt` and `JetBrainsMono-OFL.txt`. Source: https://github.com/google/fonts/tree/main/ofl/inter and https://github.com/google/fonts/tree/main/ofl/jetbrainsmono. Anton and Space Mono remain available for the original presentation/banner artwork.

`team-petar.png`, `team-stefan.png`, and `team-zeljko.png` are the original portraits extracted from slide 5 of the owner-supplied project presentation. Names and role labels follow that slide. These assets are not fictional founder portraits.
