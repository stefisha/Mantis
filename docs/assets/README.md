# Repository presentation assets

- `banner.svg`: editable artwork for the GitHub README, using the existing Mantis mark and black/orange project identity.
- `banner.png`: 1280 × 400 raster export, so GitHub renders the bundled Anton and Space Mono typography consistently.
- `workspace.png`: screenshot of the actual local application with no private manuals or credentials.

The banner source embeds the original Mantis mark. The PNG was rendered from that SVG with resvg using `static/assets/Anton-Regular.ttf` and `static/assets/SpaceMono-Regular.ttf`. Font licenses and brand provenance are documented in [the application asset guide](../../static/assets/README.md).
