# Repository presentation assets

- `banner.svg`: editable artwork for the GitHub README, using the existing Mantis mark and black/orange project identity.
- `banner.png`: 1280 × 400 raster export, so GitHub renders the bundled Anton and Space Mono typography consistently.
- `product.jpg`: screenshot of the real product landing page.
- `workspace.jpg`: screenshot of the actual Your chats drawer with a saved example conversation and no private manuals or credentials.

The banner source embeds the original Mantis mark. The PNG was rendered from that SVG with resvg using `mantis/web/assets/Anton-Regular.ttf` and `mantis/web/assets/SpaceMono-Regular.ttf`. Font licenses and brand provenance are documented in [the application asset guide](../../mantis/web/assets/README.md).
