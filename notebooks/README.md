# Research archive

These files preserve the original Mantis experiments. They are not runtime dependencies of the maintained application.

| File                        | Experiment                         |
| --------------------------- | ---------------------------------- |
| `Report_Rag.ipynb`          | Early PDF retrieval and generation |
| `Report_Front.ipynb`        | Early Streamlit interface          |
| `Whisper_model.ipynb`       | Speech transcription               |
| `grounding_dino_demo.ipynb` | Text-prompted object detection     |
| `legacy_report_rag.py`      | Legacy entry-point guidance        |

Use `mantis` or `python -m mantis` for the maintained product page and maintenance workspace. Never add API keys, private manuals, or saved sensitive outputs to these notebooks.
